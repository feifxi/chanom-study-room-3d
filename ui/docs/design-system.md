# Connecta Design System

คู่มือสำหรับ HTML demo ที่พอร์ต 3200 ใช้สเกลตัวอักษร สี และองค์ประกอบจากหน้าในเดโมนี้ ดูประวัติการปรับหน้าต่าง ๆ ใน [DESIGN.md](../DESIGN.md)

## Typography

- **Nunito** ใช้กับ UI ภาษาอังกฤษ หัวเรื่อง ปุ่ม และตัวเลข
- **IBM Plex Sans Thai** ใช้เป็น fallback สำหรับอักษรไทย
- **JetBrains Mono** ใช้เฉพาะข้อความที่ต้องจัดแบบ monospace ตัวเลขราคาใช้ Nunito กับ tabular numerals

| บทบาท | ขนาด | น้ำหนัก |
| --- | --- | --- |
| หัวเรื่อง Landing | 36–66 px ตามความกว้างหน้าจอ | 850 |
| หัวข้อแต่ละส่วนบน Landing | 29–44 px | 850 |
| ชื่อหน้าในแอป | 28 px เดสก์ท็อป / 24 px ต่ำกว่า 768 px | 800 |
| ชื่อหน้า Log in / Sign up | 32–38 px ตามหน้าจอ | 850 |
| ชื่อแพ็กเกจ Plus | 20 px | 850 |
| ราคา Plus | 28 px | 750 |
| เนื้อหาทั่วไป | 14–16 px | 400–600 |
| ข้อความแชต | 15 px เดสก์ท็อป / 13 px มือถือ | 400 |
| ป้ายกำกับและข้อความช่วย | 12–13 px | 400–750 |
| ปุ่มหลัก | 14–15 px | 800 |

## สีและสถานะ

**Thai tea** เป็นพาเลตหลัก ส่วน Light, Dark และ System ควบคุมโหมดการแสดงผล

| Token | Light | Dark | การใช้ |
| --- | --- | --- | --- |
| `--primary` | `#e8772e` | `#ff9a52` | พื้นหลังปุ่มหลัก |
| `--primary-ink` | `#c25a14` | `#ffb784` | ข้อความเน้นและไอคอน |
| `--secondary` | `#ffead9` | `#3a2618` | พื้นหลังพื้นที่เน้นและตัวเลือกที่เลือกอยู่ |
| `--ring` | `#e8772e` | `#ff9a52` | เส้น focus และสถานะที่เลือก |
| `--background-2` | `#fbeee3` | `#1f1712` | พื้นหลังชั้นเสริม |

พื้นหน้า การ์ด ข้อความ และเส้นขอบอิง `--background`, `--card`, `--foreground` และ `--border` ตามโหมด ปุ่มสีส้มในหน้าบัญชีใช้ข้อความสีน้ำตาลเข้ม `#23150d` เพื่อแยกตัวอักษรจากพื้นหลังชัดเจน

## Layout และองค์ประกอบ

- **Spacing.** ใช้กลุ่มระยะ 4, 8, 12, 16 และ 24 px สำหรับจัดแนวองค์ประกอบ เว้นระยะระหว่างส่วนใหญ่ตามขนาดจอ
- **ปุ่ม.** ปุ่มหลักหน้าบัญชีสูงอย่างน้อย 46 px ปุ่มรองใช้พื้นเป็นกลาง ปุ่มลิงก์เชิญแสดงลูกศรด้านขวาเมื่อ hover หรือโฟกัสด้วยคีย์บอร์ด
- **Log in และ Sign up.** หัวเรื่องชิดซ้าย ปุ่ม Google และ Discord เป็นปุ่มยาวเต็มแถว วางเหนือฟอร์มอีเมลโดยเว้นระยะระหว่างกลุ่ม ปุ่มส่งฟอร์มใช้สี Thai tea
- **การสร้างตัวละคร.** บนจอกว้างภาพพรีวิววางซ้ายและตัวเลือกวางขวา บนจอแคบแถว Accessories ใช้ความกว้างเต็ม ทุกตัวเลือกมีชื่อและสถานะ `aria-pressed`
- **Discover.** หน้าสมาชิกใช้แถบนำทางของแอป ส่วน Guest Discover ใช้โลโก้ Connecta แบบคงที่ ไอคอน Discover และโปรไฟล์ Guest ด้านล่าง เมนู Guest แสดงชื่อที่ตั้งไว้ สถานะ Guest ปุ่ม Change account ที่พาไป Log in และ Sign out โดยใช้ไอคอนด้านซ้ายและลำดับข้อความแบบเมนูบัญชีสมาชิก การ์ดห้องใช้ภาพปก ชื่อห้อง และปุ่มเข้าห้อง
- **Plus.** Landing แสดงราคาและฟีเจอร์ Free เทียบกับ Plus ในตารางสำหรับอ่าน บนหน้า Plus การ์ด Free และ Plus วางคู่กันบนจอกว้าง วางเรียงลงมาบนมือถือ ราคาใช้สวิตช์ Monthly / Yearly ร่วมกัน
