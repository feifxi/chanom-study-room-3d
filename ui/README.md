# Connecta HTML playground

แยก UI จาก `Project-StudyRoom3d/demo` มาทดลองแก้หน้าตาใน HTML โดยตรง
ต้นฉบับเป็น Next.js แต่ชุดนี้ใช้ HTML + CSS + JavaScript ธรรมดา ไม่มีขั้นตอน build ตอนเปิดดู
นี่เป็นสำเนาของเดโม ณ เวลาที่ดึง ดูเวลาที่ `manifest.json` และไม่ sync กับโปรเจกต์จริงอัตโนมัติ

## เปิดใช้งาน

- ดับเบิลคลิก `home.html` เพื่อเปิดหน้าหลัก หรือ `index.html` เพื่อเปิด Landing
- เปิด `catalogue.html` เพื่อดูรายการหน้าทั้งหมด รวมถึงหน้าต่างตั้งค่าและพาเนล
- ดับเบิลคลิก `start.cmd` เพื่อรันเซิร์ฟเวอร์และเปิด <http://localhost:3200/home.html> อัตโนมัติ กด `Ctrl+C` ในหน้าต่างคำสั่งเพื่อหยุดเซิร์ฟเวอร์
- ถ้าใช้ VS Code สามารถเปิดโฟลเดอร์นี้แล้วใช้ Live Server ได้

ไม่ต้อง `npm install` สำหรับการเปิดดู ใช้ Node.js เฉพาะเมื่อเลือกเปิด local server
กดแท็บ **Demo** ทางขวาเพื่อเปลี่ยนธีม Light / Dark และชุดสี หรือไปหน้าต่าง ๆ

## ขอบเขตของต้นแบบ

- ปุ่มเปลี่ยนหน้าหลัก แท็บที่แยกเป็นหน้า และหน้าต่างหลักเชื่อมให้ลองเดินดู UI ได้
- ธีมและชุดสีใช้ได้ทั่วหน้าและจำค่าในเบราว์เซอร์
- ช่องกรอกข้อความและสวิตช์ใช้ทดลองหน้าตาได้ การบันทึกเป็นเพียง feedback ในหน้าตัวอย่าง
- ไม่มี React, Next.js, Three.js, WebGL, ไมโครโฟน, เสียง, วิดีโอ, WebSocket หรือระบบแชทใน runtime
- แชท/ข้อความที่มองเห็นเป็น UI และข้อมูลตัวอย่างจากเดโม ไม่มีการส่งข้อความ
- หน้าล็อกอิน การสมัคร การซื้อ และการชำระเงินเป็นหน้าตัวอย่าง ไม่มีการเรียกบริการจริง
- พื้นที่ห้องและตัวละครเป็นภาพแคปจากเดโมจริง ไม่ใช่ภาพที่สร้างด้วย AI
- การหมุนตัวละคร การเดิน และการเปลี่ยนรูปลักษณ์ 3D จะไม่ทำงาน เพราะใช้ภาพนิ่ง
- หน้าต่างบางสถานะเป็นไฟล์ HTML แยก การแก้ header หรือเนื้อหาที่ซ้ำกันต้องแก้ในไฟล์ที่เกี่ยวข้องด้วย
- ปุ่มย่อยที่ไม่ได้เชื่อมไว้คงไว้เพื่อดู/แก้ UI ไม่มี business logic จากเดโมติดมาด้วย

ห้องมี markup มือถือและเดสก์ท็อปแยกกันในไฟล์เดียว เพราะเดโมต้นฉบับเปลี่ยน HUD ด้วย JavaScript
แก้ส่วน `.ui-desktop` และ `.ui-phone` หากปรับ HUD ของห้อง

1. เปิดเดโมต้นทางที่พอร์ต 3100
2. รัน `npm run capture` จากโฟลเดอร์นี้
3. เปิด local server ด้วย `npm start` แล้วรัน `node tools/verify.mjs` เพื่อตรวจหน้าและแคปภาพ

หากต้องการดึงใหม่บางหน้า:

```powershell
node tools/export-demo.mjs home settings-character
node tools/build-html.mjs
```

เครื่องมือดึงใหม่ไม่แก้ซอร์สในโปรเจกต์จริง ไม่ commit และไม่ deploy
