# Decision log

Short records of choices that shaped the project, newest last. Each says what we chose and why,
so a later change can be made knowingly.

| Date    | Decision                                                                                            | Why                                                                                                                                                                       |
| ------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10 | **Colyseus** for real-time rooms                                                                    | Rooms, delta-synced state and reconnection out of the box; TypeScript end to end.                                                                                         |
| 2026-10 | **Next.js + React Three Fiber**, rewritten from the Vite prototype                                  | One React codebase for the lobby, HUD and 3D scene; the old prototype lives on the `agent-hq` branch.                                                                     |
| 2026-10 | **Drizzle + Postgres** (not Prisma)                                                                 | SQL-shaped and light; migrations are plain SQL files that run when the game server boots.                                                                                 |
| 2026-10 | **LiveKit** for voice and screen share                                                              | A self-hostable SFU; proximity volume and table-only screen subscriptions are done client-side.                                                                           |
| 2026-10 | **Anonymous join**, no accounts                                                                     | It's a demo for friends; a random `visitorId` in localStorage is enough to group stats. Better Auth stays an option for later.                                            |
| 2026-10 | **Public rooms only**, a new room opens at 20 people                                                | Simplest way to never turn anyone away; private rooms are in the backlog.                                                                                                 |
| 2026-10 | **pnpm with `node-linker=hoisted`**                                                                 | Isolated installs created two copies of `@colyseus/core`, which split the matchmaker.                                                                                     |
| 2026-10 | **Server-authoritative NPCs** with shared A* pathfinding                                            | Everyone sees the same cats and buddies; the same navigation code runs on the server and in tests.                                                                        |
| 2026-10 | **Buddy Machine is summon + goodbye only**                                                          | Renaming, settings, talking and rare drops made it complicated; summoning is the fun part.                                                                                |
| 2026-10 | **Personal pomodoro only** (no room timer)                                                          | People study on their own schedule; the room shows everyone's status instead.                                                                                             |
| 2026-10 | **Screen shares only reach your table**                                                             | Privacy and bandwidth: subscriptions follow seat groups (a table, or the sofa).                                                                                           |
| 2026-10 | **E interacts with the closest thing**, and a cat following you is never a target                   | A following cat used to block sitting down.                                                                                                                               |
| 2026-10 | **Cosy palette, simple lobby**; Connecta used for structure only                                    | The Connecta landing page and colours didn't fit; its HUD layout (rail, dock, zoom) did.                                                                                  |
| 2026-10 | **Tailwind through `@tailwindcss/postcss`**                                                         | The experimental Turbopack loader served stale `globals.css` in dev.                                                                                                      |
| 2026-10 | **Lobby, room and admin render client-side only**                                                   | They're built from localStorage or need a session cookie; no SEO is needed.                                                                                               |
| 2026-10 | **`noEmit` in the shared tsconfig; VS Code uses the repo's TypeScript**                             | No package builds with `tsc`; TypeScript 6 (bundled with VS Code) demands `rootDir` otherwise.                                                                            |
| 2026-10 | **Feedback asked once, when leaving**                                                               | Asking on arrival gets dismissed; leaving is when people have an opinion. Skip asks again at most daily.                                                                  |
| 2026-10 | **Admin password from `ADMIN_PASSWORD`**, checked server-side, signed HttpOnly cookie               | A password in code would ship to every browser and to GitHub.                                                                                                             |
| 2026-10 | **`/admin` = product analytics, Grafana = service health**                                          | Two audiences: "do people like it?" vs "is it reliable, and why not?".                                                                                                    |
| 2026-10 | **Keep Grafana/Prometheus/Loki** (not only CloudWatch)                                              | The project is also for learning SRE practices: SLOs, burn-rate alerts, incident debugging.                                                                               |
| 2026-10 | **Grafana Alloy** for log shipping (not Promtail)                                                   | Promtail reached end of life; Alloy is its replacement.                                                                                                                   |
| 2026-10 | **SLO rules and the dashboard are generated** from small Python scripts                             | One table defines each SLO; every window and alert follows the same formula without typos.                                                                                |
| 2026-10 | **Declare runtime env vars in `turbo.json`**                                                        | Turborepo 2 silently drops undeclared env vars, which hid chaos and password overrides.                                                                                   |
| 2026-10 | **Tests:** Vitest for pure logic, a WebSocket smoke test, Playwright for the browser (always muted) | Fast feedback for rules and reducers; one real-browser suite for the flows people use. Headless Chrome once played test audio out loud, so every run uses `--mute-audio`. |
| 2026-10 | **RDS for the playtest database** (not Postgres in a container)                                     | Managed backups and metrics, production-like for SRE practice; at $0.023/hour it still fits the $20 budget. Stopped or snapshot-and-deleted between playtests.            |
| 2026-10 | **Delegate only `studyroom.chanombude.me` to Route 53**                                             | The main domain keeps Namecheap DNS and its email forwarding; Terraform owns everything under the subdomain.                                                              |
